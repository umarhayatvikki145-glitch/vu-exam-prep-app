# VU Exam Prep App (PAK301)

AI-powered exam preparation app built with React — interactive MCQ practice with smart progress tracking.

## Features
- Story-style reading notes, split into navigable parts
- 3-part MCQ practice with 90% unlock threshold per part
- Chapter-wide question history — no repeated questions
- Color-coded question tags (Past Paper / Handout / Tricky / Concept / Trap)
- Background question loading for smooth experience
- AI-generated questions via Anthropic Claude API

## Tech Stack
React (single-file app, ~1,400 lines) · Anthropic API · Tailwind CSS

## Result
Built and used this app for my PAK301 midterm — scored 90%.
